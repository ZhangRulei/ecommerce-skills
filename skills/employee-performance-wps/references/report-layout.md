# 日报版式

同一工作簿保留两张业务表：

- Sheet1：逐日逐员工明细，A至G列依次为日期、员工、业绩、高客单业绩、分数、订单数、高客单订单数。
- 业绩日报：员工纵向分块，日期横向从新到旧。A列合并显示员工，B列为指标，C列起为日期。

每个员工六行指标：个人账号归属业绩汇总、优质用户账号业绩、高客单业绩、高客单分数、高客单数量、总计；块间留一行。总计为个人账号业绩加优质账号业绩，不能重复加高客单业绩。

优质用户账号业绩先留空，刷新时保留后续人工填写的值或公式。没有输入记录的历史日期保持空白，不根据参考截图抄写历史金额。高客单业绩/分数/数量为0时，显示格式可留白，但底层保留真实0。

字体宋体11号，员工姓名居中，金额右对齐，总计行浅绿色RGB(198,224,180)，浅灰细网格线。日期列新增时插入正确倒序位置，保留原有日期数据。

## 冻结窗格

在WPS网页版中回到表格左上角，选中C2，使用“视图 → 冻结窗格 → 冻结至活动单元格（1行B列）”。如果窗口太窄，先临时调小工作簿的“显示比例”，让A至C列同时完整可见，再操作并恢复常用比例。存在旧冻结时，先取消旧冻结。

实际接入中，脚本环境的窗口冻结设置与网页当前视图出现过差异，因此同步脚本不重设冻结；在网页设定一次并核对实际滚动效果。不要只看到脚本返回一个true就认为冻结范围正确。
